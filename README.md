# Notes List (Из Т-Академии)

Это приложение — интерактивный менеджер заметок, предлагающий удобный UX благодаря динамической группировке записей в "стопки". Приложение автоматически распределяет задачи по датам, прячет неважные дела в раскрывающиеся интерактивные стэки и предоставляет гибкие настройки отображения интерфейса.

# 🛠 Tech Stack

**UI**: Гибрид XML и Jetpack Compose

**Architecture**: Clean Architecture (Data, Domain, Presentation).

**DI**: Manual Dependency Injection (DI Containers)

**Asynchrony**: Kotlin Coroutines & Flow (StateFlow, combine, debounce, flatMapLatest).

**Database**: Room, DataStore (для хранения конфигурации стопок).

**Custom Views**: Сложные кастомные вью-контейнеры со своей логикой измерения (onMeasure), размещения (onLayout) и отрисовки (Canvas + StaticLayout для оптимизации рендеринга текста).

# 🚀 Key Features

**Динамическая группировка в стопки (Custom NoteStackView)**: Неважные заметки автоматически упаковываются в стопку. Реализована плавная анимация раскрытия и сворачивания элементов стэка на базе TransitionManager и ChangeBounds.

**Высокопроизводительный NoteView**: Полностью кастомная вью для отрисовки карточки заметки. Чтобы избежать тяжелых XML-иерархий, все элементы (заголовок, описание, дата, приоритет и статус прочтения) рисуются вручную на Canvas.

**Адаптивность (Multi-pane Layout)**: Использование SlidingPaneLayout позволяет комфортно пользоваться приложением как на смартфонах, так и на планшетах. В портретном режиме экран деталей открывается слайдом поверх списка, а в ландшафтном — оба экрана отображаются одновременно.

**Реактивный UI и дебаунс поиска**: Поиск заметок работает в реальном времени. Ввод пользователя обрабатывается оператором debounce(500ms), что предотвращает лишние запросы к базе данных Room при быстром наборе.

**Кастомизация интерфейса**: В настройках можно менять расстояние между картами в свернутой стопке (stackSpacing) и ограничивать максимальное количество одновременно видимых карт в стэке (stackMaxVisible).
